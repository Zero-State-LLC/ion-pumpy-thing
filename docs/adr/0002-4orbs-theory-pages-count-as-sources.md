# 4orbs theory pages count as sources

Status: accepted

The game exists to teleport the airliner using the concepts Ashton Forbes and 4orbs.com set out, so a claim may rest on any 4orbs.com page: the reviewed pages (the corrected Part Three, the measurement page, `/research/` and `/science/101/`), the auto-generated `/library/theories/` pages even though they say they are not yet editorially reviewed, and a stream once 4orbs.com gives it a `/library/videos/` page. A theory page's reading is labelled 4orbs account; published physics it relies on keeps its own label, cited to the paper. The source register records which cited pages are unreviewed; player-facing text does not, since the game takes the premise as given.

When a reviewed page and a theory page disagree, the game uses whichever makes the Teleport possible, and may add theory to reviewed data where the reviewed data alone would stop short. Every such choice is recorded in the source register: both pages, what each says, and why the game takes the one it does.

## Considered options

- **Reviewed pages only**: the register's earlier caution ("a page being fetched recently does not prove its wording is corrected"). It would have kept most of the ion pumpy material out, because the dense plasma focus, electron screening, undulator and dynamic Casimir readings are almost all on theory pages.
- **A reviewed page always wins a conflict**: the register's existing "record the conflict; do not blend statements". It would stop the run short of the Teleport wherever reviewed pages are cautious, for example where they find no source for the pump's piston and say lab machines fire only once.
- **Streams directly, cited by timestamp**: fastest, but auto-captions of a long stream can't be quoted reliably, and 4orbs.com already archives streams as video pages.

## Consequences

- Updating the register with a theory-page claim still bumps the source revision, so saved runs made against the older sources start fresh.
- A theory page can change or vanish without a corrections entry.
