Privacy

Ion Pumpy Thing is a browser game published by Zero State LLC. You do not create an account to play it.

Progress on this device

The game stores your run, settings, and timed best in this browser, on this device. Starting a new run replaces stored progress but keeps your timed best. If browser storage is blocked, the game stays playable and tells you it cannot save. Private browsing or clearing site data can remove that progress. Nothing here is sent to our servers.

The practice board

An optional shared practice board exists only when the game runs as a Claude artifact with access to a scores-v2 database. On this website that board is unavailable, and your timed best stays on this device. Learning runs do not post scores.

Measurement on this website

On the production host ion-pumpy-thing.app only, this site loads Google Analytics 4 (measurement ID G-TEC2RE9FGC) so Zero State can see aggregate visits. The tag is not loaded on localhost, preview hosts, or ion-pumpy-thing.pages.dev. Google’s own processing is described in the Google Privacy Policy.

Fonts

The pages load IBM Plex and Saira Condensed from Google Fonts.
